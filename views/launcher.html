Getting Started

New to self-hosting? Follow these steps once to go from a fresh server to a live site.

1
Add your SSH key to the server

This lets this tool connect without a password. See SSH Key Setup at the bottom of this page — copy the command and run it in your server provider's web console.

2
Clone & install open-folio on the server

Downloads the open-folio code to your server and installs dependencies. Requires git and Node.js 18+ on the server.

3
Run first-time configuration on the server

Open an SSH terminal and run npm run setup to set your admin password and configure environment variables.

4
Push your content to the server

Uploads your local database and all images so the site has your data.

5
Start the site with PM2

PM2 keeps your site running after you disconnect. Install it first with npm install -g pm2 && pm2 startup via SSH, then click below.
